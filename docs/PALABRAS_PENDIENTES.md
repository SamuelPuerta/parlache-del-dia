# Palabras pendientes de verificación

Regla del plan: no se incluye en `backend/data/words.json` ninguna palabra cuyo significado no se haya verificado en una fuente confiable (por ejemplo el Diccionario de americanismos de la ASALE). Aquí se anotan las pendientes.

Lista de arranque sugerida por el plan (todas por verificar): parce, pelao, guaro, cucho, tinto, bacán, rumba, paila, pilas, tombo, lucas, vaina, paisa, arepa, chuzo, plata.
